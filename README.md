# ScholarMind（智读）🧠📚

> 一个多智能体协作系统：把复杂的计算机学术论文，自动转化为结构清晰、深入浅出的解读报告。

## 这是什么

读论文是科研和学习的高频痛点：方法密集、实验冗长、门槛高。ScholarMind 模拟一个**专家研讨小组**——多个角色各异的智能体分工协作，从方法论、实验设计到批判性洞察，逐层拆解一篇论文，最终输出一份人能快速读完的解读报告。

## 多智能体如何协作

| 角色 | 职责 |
|------|------|
| **方法论者** | 拆解论文的核心方法与技术路线 |
| **实验评审** | 评估实验设计、数据集与指标是否合理 |
| **批评家** | 给出批判性洞察：局限性、可复现性、潜在坑 |
| **综述者** | 汇总各方意见，生成结构化报告 |

（如你的实现里角色划分不同，改成实际的分工即可）

## 功能

- 📄 输入论文（PDF/链接），输出结构化解读报告
- 🧠 多智能体研讨式解析：方法 → 实验 → 批判 → 综述
- 🗂️ 报告结构清晰：核心贡献、方法拆解、实验分析、局限与展望

## 快速开始

```bash
git clone https://github.com/WilShi/ScholarMind_MAS.git
cd ScholarMind_MAS
pip install -r requirements.txt
# 配置模型 API key（见 config 示例）
python main.py --paper <你的论文.pdf>
```
